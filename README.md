# Philosophy Books Notes

[English](README.md) | [Spanish](README.es.md)

Welcome to **philosophy-books-notes**.

This repository contains structured notes on philosophers and philosophical works. Its purpose is to build a personal but organized knowledge base covering major thinkers, concepts, and interpretations.

At the moment, most of the content is written in **Spanish**, but the repository may expand to include English content or multilingual notes in the future.

Currently, the notes are managed using **Obsidian**. The structure is fully Markdown-based and designed to work as an Obsidian vault.

In the future, this repository may also include a publishing workflow using **mdBook** or a similar documentation tool.

## Goals

- Maintain organized notes on philosophers and their works
- Build a connected knowledge graph of philosophical concepts
- Keep content portable and version-controlled
- Potentially publish structured documentation in the future

## Tools

- Markdown
- Obsidian (current)
- mdBook (planned / optional)

## Notes

This repository is primarily for personal study, but it may become more structured and shareable over time.
