# Notas de Libros de Filosofía

[English](README.md) | [Español](README.es.md)

Bienvenido a **philosophy-books-notes**.

Este repositorio contiene notas organizadas sobre filósofos y obras filosóficas. Su objetivo es construir una base de conocimiento personal pero estructurada, cubriendo autores importantes, conceptos e interpretaciones.

Por ahora, la mayoría del contenido está escrito en **español**, pero en el futuro el repositorio podría expandirse para incluir contenido en inglés o notas multilingües.

Actualmente, las notas se gestionan usando **Obsidian**. La estructura es completamente basada en Markdown y está pensada para funcionar como un vault de Obsidian.

En el futuro, este repositorio podría incluir también un flujo de publicación usando **mdBook** u otra herramienta similar.

## Objetivos

- Mantener notas organizadas sobre filósofos y sus obras
- Construir una red conectada de conceptos filosóficos
- Mantener el contenido portable y versionado
- Posiblemente publicar documentación estructurada en el futuro

## Herramientas

- Markdown
- Obsidian (actual)
- mdBook (planeado / opcional)

## Nota

Este repositorio está pensado principalmente para estudio personal, pero con el tiempo podría volverse más estructurado y compartible.
